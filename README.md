# Airship-Modding Us

este mod é a continuação do Modding us,um mod que trazia a versão antiga do Among us mais especificamente 22/23.

# Em relação a este mod 

este mod vai receber atualizações até 2028 e funcionará no computador, Android e web

# Funções personalizadas
Funções personalizadas integradas:

Engenheiro (Você pode usar as aberturas de ventilação)
Xerife (Você precisa atirar no impostor)
Médico (você pode reviver cadáveres)
Bobo da Corte (você vencerá se for eliminado pela votação)
Pelicano (você pode comer os tripulantes)
Clean (você pode arrastar corpos)
# gamemode 
trinca (mate a trinca mas se o outro fizer a trinca aleatória perde)

bed Wars (a duas equipes de tripulantes,cada um com um poder diferente e eles tem q roubar a cama dos adversários usando seus poderes quem conseguir passar três vezes ganha)

Fogo Amigo ( luta intensa cada um por se use dutos e mate, sabotagens são proibidas é luta até o final detalhe não a poderes extras

# Guia de instalação 
Android.
1. vá na aba realeses
2. irá ver alguma coisa como moddingus-airship.apk
3. clique encima dele.
4. se não desativou downloads fora da play store desative.
5. quando o mod terminar de baixar clique em cima dele e o app será instalado diretamente no seu celular

computador 🖥️ 💻 

1.irá ter um arquivo.dll e você vai clicar nele

2.vá na área de transferências 

3. O mod estará lá disponível para você baixar
